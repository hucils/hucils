## I. Preface

I am an autistic trans woman with a particular fondness for artificial intelligence and for the slightly
improvisational craft of *vibe coding*: letting curiosity set the course and rigour follow close behind.

My work wanders between disciplines: embedded robotics, graphics engines, functional system configuration
and the preservation of the online worlds I grew up in. Each project here began as a question I could not leave alone.
